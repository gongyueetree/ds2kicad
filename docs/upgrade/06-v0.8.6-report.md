2. **可选尺寸 null 被还原成 0**：`Number(null)===0` 让"已清空"在二次 sanitize 后变回 0。
3. **`fetch-pdf` 调用方式不匹配**（item 11），本地图集渲染必然失败。

## 追加修复：线上图集缩略图空白（真实根因）

`server/dev.js` 的 handler 调用方式只影响本地；**线上（Vercel）的根因是另一个**：
`/api/fetch-pdf` 依赖 `PDF_TOKEN_SECRET` 做 HMAC，而该密钥若未显式配置则每个 Serverless 实例
各自随机 → extract 实例签发的令牌在 fetch-pdf 实例验不过 → 403 → 图集必然空白；
即便配了密钥，慢速源站（analog.com 等）也会因**二次完整下载**而超时。

修复：新增 `GET /api/job-pdf?jobId=…`
- 用 **JobStore + 会话鉴权**授权（多实例天然一致，不依赖跨实例共享密钥）；
- 优先返回 extract 时缓存在 Job IR 中的 PDF 字节（≤6MB），**不再二次回源**；
- 仅缓存缺失时才回源，且走 SafeDownloader；
- 上传通道（`local:`）无字节可用时返回 409 明确报错，不再静默空白。
前端图集与裁剪改用该端点；FigureGallery 增加逐图错误与空白裁剪提示。
测试：v086 反例13（缓存字节原样返回 / 401 / 跨租户 403 / 未知 job 400 / local 409）。
