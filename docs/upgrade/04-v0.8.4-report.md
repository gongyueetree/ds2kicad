## 反例测试实际发现并修复的 5 个真 bug

1. **`num is not defined`**（v0.8.3 改管脚主键时的遗留引用）导致 `/api/generate` 抛异常、HTTP 请求永久挂起 —— 这也是本轮测试最初"超时"的根因。
2. **CTRL 正则 `/g` 状态**：连续调用 `.test()` 会因 lastIndex 漏判第 2、4… 次输入（item 8 指出的问题被实证）。
3. **Legacy `DEF`/`F1` 未转义 MPN**：注入换行可伪造第二个 DEF 行。
4. **`sanitizePackage` 丢弃 `evidence`**：闸门永远看不到字段级证据锚点（item 6 形同虚设）。
5. **管脚删除墓碑只按 pinId**：重算时 pinId 重新生成，已删管脚会复活；改为 pinId + rawNumber 双键。

## 部署必读

1. **生产必须设 `DATABASE_URL`（PostgreSQL）**，且**不得设 `JOBSTORE_FILE`**，否则启动失败。首次部署需执行 `PG_SCHEMA_SQL`（`PostgresJobStore.connect()` 会自动 migrate）。
2. 生产必须配置 `EZPLM_JWT_ISS` 与 `EZPLM_JWT_AUD`，否则所有请求 401。
3. `PDF_TOKEN_SECRET`、`VITE_EZPLM_ORIGINS` 仍为生产必填（v0.8.1/v0.8.2 起）。
