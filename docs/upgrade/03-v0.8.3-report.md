## 反例测试实际发现并修复的 3 个真 bug

1. **人工修改的管脚被 rawPins 重算冲掉**（审核白做）→ `sanitizePinsets` 以 `reviewerEdited` 标记合并回人工值。
2. **未知家族仍生成 footprint**：`kicadgen` 自维护的 UNSUPPORTED 列表漏了 unknown/qfp/power_tab → 改为统一取 `validate.js` 的 allowlist 判定。
3. **`descr`/`tags` 未转义**导致注入引号可破坏 s-expression → 接入 `escSexpr`。

## 已知行为变更（部署必读）

1. 所有接口要求**已认证 ezPLM 会话**；本地联调可设 `AUTH_MODE=dev`（此时匿名身份 → 结果一律 non-promotable）。
2. `/api/generate` 的 patch 主键从名称改为**稳定 ID**（`includePackageIds` / `packageId`）。
3. jobId 现在是服务端 UUID；`JOBSTORE_FILE` 默认 `:memory:`，**Serverless 多实例/重启会丢作业**——生产必须指定持久化文件或改 Postgres 适配器。
